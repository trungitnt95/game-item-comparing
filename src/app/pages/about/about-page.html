Dữ liệu

  • Nguồn: {{ dataSource.name }} – {{ dataSource.publisher }}.
  • {{ catalog.foods.length }} thực phẩm thuộc {{ catalog.groups.length }} nhóm, {{ catalog.nutrients.length }} chỉ số dinh dưỡng. {{ dataSource.basis }}.
  • “—” nghĩa là bảng gốc không có số liệu, không phải bằng 0.
  • Dữ liệu JSON dùng được trực tiếp (vd cho script hoặc AI): @for (file of dataFiles; track file; let last = $last) { {{ file }}{{ last ? '' : ', ' }} }

Thông tin chỉ mang tính tham khảo, không thay thế chẩn đoán hay tư vấn của bác sĩ, chuyên gia dinh dưỡng.

Dùng với AI qua MCP

Ứng dụng có kèm một MCP server (Model Context Protocol) để các trợ lý AI như Claude tra cứu cùng bộ dữ liệu này. Tất cả tool đều chỉ đọc.

@for (tool of tools; track tool.name) { }
Tool Chức năng
{{ tool.name }} {{ tool.description }}

1. Tải server (một file, cần Node.js 24+)

curl -LO {{ mcpUrl }}

Hoặc tải trực tiếp. File đã đóng gói sẵn dữ liệu, không cần cài thêm gì.

2a. Claude Code

claude mcp add nutrition-health -- node /duong-dan/toi/nutrition-health-mcp.mjs

2b. Claude Desktop (claude_desktop_config.json)

{{ desktopConfig }}

2c. Chạy dạng HTTP (Streamable HTTP)

PORT=3000 node nutrition-health-mcp.mjs --http
claude mcp add --transport http nutrition-health http://localhost:3000/mcp

Chế độ HTTP không lưu phiên nên deploy được lên bất kỳ host Node/Docker nào. Mã nguồn và hướng dẫn chi tiết: GitHub.
